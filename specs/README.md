# specs/

Тут зберігаються технічні завдання в тому вигляді, в якому вони були передані.

Правила:
- Файл іменується `NN-коротка-назва.md` (напр. `01-landing.md`).
- Оригінал не редагується. Уточнення й зміни — окремими файлами `NN-...-addendum.md`
  або записами в `docs/decisions/`.
- ТЗ комітиться **до** початку виконання робіт по ньому.
